# Day 17 – Agentforce AI

## Agentforce Summary

Agentforce is Salesforce's AI-powered platform that enables organizations to build intelligent AI agents capable of understanding requests, reasoning through tasks, interacting with business systems, and performing actions automatically.

Agentforce agents can:

- Answer user questions
- Retrieve information from databases
- Execute Flows and Apex actions
- Automate business processes
- Assist employees and customers
- Integrate with enterprise applications

Agentforce combines AI reasoning with Salesforce automation to improve productivity and decision-making.

# Task 2 – AI Workflow Thinking

## Workflow

User asks question
↓
AI Agent
↓
Flow / Apex
↓
Database
↓
Response Generation
↓
Action Execution

---

## Step-by-Step Explanation

### 1. User Asks Question

Example:

"How many classes have I attended this semester?"

The request is sent to the AI agent.

---

### 2. AI Agent

The AI agent understands:

- User intent
- Required information
- Necessary actions

The agent determines what needs to be done.

---

### 3. Flow or Apex

The agent invokes:

- Salesforce Flow
- Apex Action
- API Service

to retrieve or process data.

---

### 4. Database Access

The system retrieves information from:

- Student records
- Attendance tables
- Course databases

---

### 5. Response Generation

AI converts raw data into a natural language response.

Example:

"You attended 82 out of 100 classes. Your attendance percentage is 82%."

---

### 6. Action Execution

The agent can also perform actions such as:

- Sending emails
- Creating records
- Updating data
- Triggering approvals

---

# Task 3 – Risks of AI Systems

## 1. Hallucinations

AI may generate incorrect information confidently.

Example:

Providing wrong attendance percentages.

---

## 2. Wrong Automation

Incorrect automation may update records improperly.

Example:

Approving invalid leave requests.

---

## 3. Privacy Risks

Sensitive information may be exposed.

Examples:

- Student records
- Faculty information
- Financial data

---

## 4. Bias

AI decisions may unfairly favor certain groups if training data is biased.

---

## 5. Incorrect Approvals

AI may approve requests without proper validation.

Examples:

- Scholarship approvals
- Budget approvals
- Recruitment decisions

---

## 6. Over-Automation

Too much automation can remove necessary human oversight.

Critical decisions should still involve humans.

---

## Why Should Enterprises Carefully Control AI Systems?

Enterprises must control AI because:

- Business decisions affect real people.
- Incorrect actions can cause financial losses.
- Data privacy must be protected.
- Regulatory compliance must be maintained.
- Human review is required for critical decisions.

AI should assist humans rather than completely replace them.

# Task 4 – Reflection

## How Might AI Agents Change Enterprise Software Development in the Next 5 Years?

AI agents will significantly transform enterprise software development by automating repetitive tasks and improving productivity.

Expected changes include:

- Automatic code generation
- Intelligent testing and debugging
- Automated documentation creation
- Faster requirement analysis
- Smart workflow creation
- Automated system monitoring
- Improved customer support systems

Developers will spend less time on repetitive implementation tasks and more time on system architecture, business logic, security, and innovation.

AI agents will become collaborative development partners rather than simple automation tools.
